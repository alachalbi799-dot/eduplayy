# EduPlay
interactive learning app that helps students understand lessons through text, images, audio, video, and quizzes, with results shown at the end

## How to Run

1. Navigate to the web application directory:
   ```bash
   cd apps/web
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the Next.js development server:
   ```bash
   npm run dev
   ```

4. Open your browser and go to:
   ```
   http://localhost:3000
   ```
